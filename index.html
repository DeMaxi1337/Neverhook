FAQ

Frequently Asked Questions

How do I install the mod via Geode?
Open Geometry Dash, go to the Geode menu, click 'Download', search for the mod, and click 'Install'. Restart the game to apply changes.
Is this mod free?
Yes, the mod is completely free to use. If you like it, you can support the developer via links in-game or on the Geode mod page.
My game crashes after installation, what should I do?
Ensure you have the latest Geometry Dash and Geode versions. If the issue persists, try disabling other mods to find conflicts, or contact the developer's Discord.
Where can I find saved macros or replays?
Macros and other data are usually saved in the geode/mods/ folder or a specific mod directory inside your Geometry Dash save folder (%localappdata%\GeometryDash on Windows).
How do I add keybinds?
In the mod menu, find the desired function and right-click it, or use the gear button next to it to assign a hotkey.
